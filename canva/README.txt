Designs made in Canva (folder "IGCC Instagram Posts") and exported here as PNG.
Name each file after the date it should be posted: 2026-11-21.png
The caption still comes from calendar.json, so every file needs a calendar entry for that date.
Dates without a file here fall back to the image drawn by poster.py.
Optional: put the caption (with hashtags) in YYYY-MM-DD.txt next to the image to use it instead of the calendar caption.
